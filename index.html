Sobre el proyecto

Panel CGES es un proyecto de desarrollo de software web enfocado en construir una plataforma moderna para organizar, consultar y visualizar información de gestión.

El proyecto se encuentra actualmente en fase de desarrollo, pruebas técnicas y despliegue de infraestructura.

Objetivo técnico

El objetivo del proyecto es desarrollar una aplicación web modular, segura y mantenible que permita centralizar procesos de seguimiento y presentar información mediante interfaces modernas y paneles de control.

Componentes en desarrollo

  • Aplicación web frontend.
  • API REST para servicios de backend.
  • Autenticación y autorización de usuarios.
  • Gestión y almacenamiento de información.
  • Paneles de seguimiento e indicadores.
  • Infraestructura de despliegue en Linux.
  • Acceso seguro mediante servicios Cloudflare.

Estado del proyecto
